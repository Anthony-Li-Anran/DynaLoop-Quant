# 横截面有效因子的统计判定口径（Part A · 通道一）

更新：2026-11-15。本文是「**通道一 选股（横截面）**」判定口径的**权威来源**，与 `docs/effective_factor.md`（通道二 择时）**并列且互不隶属**。流程与验收语境见 `docs/research_process.md`，实现为 `src/dynaloop/research_engine/cross_section.py`，端到端脚本为 `experiments/factor_stream/cross_section_assessment.py`。

---

## 零、为什么必须另立口径（不是把通道二换个数据喂进去）

`docs/effective_factor.md` 的零假设是「逐期损失差分不胜过**零预测**与**历史均值**」，样本结构是「每期 1 个标量预测 vs 1 个标量目标」。把它套到横截面上会直接失效：

| | 通道一 选股（本文） | 通道二 择时 |
|---|---|---|
| 问什么 | 同一时点，标的池里**谁比谁更强** | 这只标的**接下来方向 / 关系**如何 |
| 观测 | 每期 \(N_t\) 个标的的分数向量与远期收益向量 | 每期 1 个标量预测、1 个标量目标 |
| 零假设 | **无相对排序能力** \(E[\text{RankIC}]=0\) | 不胜过零预测与历史均值两条基线 |
| 对照基线 | **随机排序**（RankIC 期望 0）/ **等权组合** | 零预测 / 历史均值 |
| 统计量 | 逐期排序信息系数（宽度加权） | 逐期损失差分 \( \min(e_0,e_{\mu})-e_f \) |
| 功效来源 | 每期标的数（宽度）+ 决策期数（长度） | 时间长度 |
| 绝对方向 | **无关**：全市场下跌但排序正确仍算有信息 | 正是断言对象 |

关键点：零预测与历史均值在横截面上是**常数向量**，对所有标的的排序恒为并列，排序信息系数恒为 0。它们不是通道一的有效基线，**必须换成随机排序与等权组合**。若把两类候选扔进同一判定族，族规模混算、零分布不再对应任何一个断言，族级错误率控制即失效。因此：

- 两条通道**各自预注册、各自冻结、各自晋升、各自出带指纹的证据条目**；
- 两通道**共用**的只有「平稳区块自助索引路径生成」与「最大统计量逐步下降」这两个**纯数学工具**（`resampling_tools.py`），**不共用族、零假设、统计量或基线**；
- 输出结论**必须带标签**「横截面有效因子」/「择时有效因子」，禁止互推：横截面结论不认证任何单只标的的进出时点，择时结论不认证任何股票池的相对排序。

**结论合成属 Part B**，不在本文范围。

## 一、三根支柱（全部落在冻结后的独立窗口）

### 支柱 0｜因果隔离（用设计消除自适应，不是用更强的检验）

- 生成、调参、反馈、策略更新等**全部自由度只作用于搜索期**；在声明的截止日 `cutoff` 把候选族与**每一个参数一次性冻结**，附数据与源码指纹。
- 验证期是 `cutoff` 之后的**历史样本外**数据，一次性评分；族与全部参数在冻结文件落盘时一次性固定，冻结动作发生在接触验证数据之前。**某轮验证窗口被查看即消耗**，再搜索 / 调参必须开新族、用新的未消耗区间，并登记前序轮次。隔离是流程 / 信息隔离，不是等未来数据物理到达。
- 由 `CrossSectionIsolationError` 强制，任何违规是硬错误、绝不静默降级：日期越界、未冻结候选、候选间验证网格不一致、期数不足、标的集合不一致、成交日不晚于决策日、标签成熟日不晚于成交日、特征可得时间晚于决策日。
- **时点成分股**：每期标的集合必须是决策日当时可得的成分股快照。`universe_provenance` 必须声明口径；若为静态 / 近似名单，判定器把 `survivorship_bias_unresolved=True` 写进 `spec` 与不宣称项，**不得宣称无幸存者偏差**（个人版裁剪，见 `research_process.md` §1.1）。

### 支柱 1｜抗数据窥探的族级检验（校正「我们搜了很多」）

- 检验对象是**冻结族里最好的那个**，不是某个预先指定的单因子。
- 逐期量：`rank_ic[t,k]` = 该期因子分数与远期收益的 Spearman 秩相关，只在两列都可得的标的上计算。**缺失标签保留为缺失，不填 0、不删除标的后压缩时间**；`N_t` 为该期有效标的数，要求 `N_t >= min_universe`（默认 30）。
- **宽度加权（通道一独有）**：排序信息系数的抽样标准误约 \(1/\sqrt{N_t-1}\)，定义 \(d_{t,k}=\sqrt{N_t-1}\,\text{rank\_ic}_{t,k}\)，使各期方差近似齐次。**宽度降低的是每期的测量噪声，不是独立决策期数**——这一点必须说清楚，不能拿「每期 300 只股票」当作「300 个独立月」。
- 观测统计量：\(T_k=\sqrt{T}\,\overline{d}_{\cdot,k}/s_k\)，取全族最大值。
- 零分布：Politis–Romano（1994）平稳区块自助（可切循环区块），**每个复制对全族共用同一条时间索引路径**，同时保留序列相关与候选间横截面相关；按各候选样本均值重新中心化，构造「无相对排序能力」零假设。学生化尺度固定在观测值、不按复制重估，也不数据依赖地剔除劣质候选。
- Romano–Wolf / Westfall–Young **最大统计量逐步下降**给出每个候选的调整后 p 值与拒绝决策。

**口径必须精确**：这是**保守的现实检验风格变体，不是完整的 SPA 检验**，也不是 Fama–MacBeth 稳健 t 值；`spec["spa_simplification"]` 与 `spec["method_boundary"]` 明确写出，不得对外宣称完整 SPA 或多变量横截面检验。高信息系数、排行榜名次、单次留出通过、描述性区间**一律不能替代本节**。

### 支柱 2｜稳定性与可重复性（独立必要条件）

显著不等于「有效」，还须同时满足：

- 验证期切成不相交的连续块，至少 `stability_fraction`（默认 75%）的块平均排序信息系数为正；
- 去掉贡献最大的那一期后，整体改善仍为正（不允许单期运气撑起结论）；
- **后半窗不衰减**：后一半决策期的平均排序信息系数不低于前一半的 `min_decay_ratio`（默认 0.5）倍，防止信号只存在于早期。这是「排序信息系数衰减」的可检验代理，**不是**半衰期估计。

块级精确符号检验 p 值**只作诊断**；块数少时功效低，**不宣称**独立的显著性保证。

## 二、通道一专属的评估指标（对齐 Qlib / alphalens，仅作报告）

以下指标按 `docs/factor_evaluation_baseline.md` 逐项对齐上游实践，**全部计算、全部留痕、全部报告，但不再作为独立于显著性的一票否决**。一线核查确认 Qlib `SigAnaRecord`、alphalens 与 qweave 都把单调性等当作描述量，不存在此类接受规则；旧版三道自创否决因此废除：

1. **分组单调性**：按因子分数把每期标的切成 `quantiles`（默认 5）组，报告各组相对**等权全池**的平均超额收益；跨期平均后的组收益向量与组序号同时报告 **Spearman 相关**与 **Kendall tau**（对齐 qweave）。`min_monotonicity`（默认 0.9）只是一条**参考线**：低于它在 `descriptive_checks` 里记录，并在结论理由中注明「描述性诊断低于阈值（非否决）」，**不拦下任何候选**。
2. **多空分腿**：最高组与最低组相对等权的超额收益**分开报告**，并分别标注方向是否符合直觉；两头方向不再作为晋升条件。A 股个人版默认 `assume_shortable=False`：空头腿是**诊断性相对收益、不等于可实盘卖空**，净收益基于只做多头的相对等权超额。T+1、涨跌停、停牌属 bar 级撮合语义（Part C），本节是 L4 **可交易性诊断、并未建模**，该限制写进 `spec["cost"]["settlement_note"]` 与不宣称项，**不得据此宣称可交易性**。
3. **成本与换手显式、毛净并列**：相邻期分组持仓的对称差给出换手；成本模型参数（双边佣金、卖出印花税、双边滑点、是否可卖空）全部进 `spec` 且全部参与计算；逐期报告**毛多空价差**与**扣成本后净可实现收益**，并把净收益符号作为描述量留痕（对齐 Qlib `risk_analysis` 含 / 不含成本并列）。**禁止**用「忽略不计」带过、禁止把毛收益当结论、禁止留不参与计算的装饰性参数。

分组单调性与多空分腿同时构成「对照基线」：随机排序的排序信息系数期望为 0，等权组合是分腿收益的基准。

## 三、数据契约（L1–L4 落到代码）

一个 `CrossSectionSlice` 是一个决策期的完整横截面：

| 字段 | 含义与强制校验 |
|---|---|
| `date` | 决策日，分数只能用到这一天为止的信息 |
| `feature_as_of` | 特征实际可得时间，必须 `<= date` |
| `execution_date` | 成交日，必须严格晚于 `date`（决策与成交分离） |
| `maturity` | 标签成熟日，必须严格晚于 `execution_date`（标签成熟后才评分） |
| `symbols` | 决策日当时的标的池快照，候选间必须完全一致 |
| `scores` | 每个冻结候选一条与 `symbols` 等长的分数向量；`None` 表示缺失 |
| `targets` | 从成交日到成熟日的远期收益，与 `symbols` 等长；`None` 表示缺失，**不得回填 0** |

禁止「收盘价算信号、同一收盘价成交」，禁止全样本标准化 / 全样本排名（所有变换窗口必须只用 `[t-w, t]`——这属于调用方契约，由 `feature_as_of` 声明，判定器强制声明存在但不假装能验证第三方计算过程）。频率 / 持有期 / 调仓间隔 / 标的池口径 / 成本参数全部进 `spec` 与指纹；分钟 / 小时数据不得混入同一判定族凑样本量。

## 四、肯定结论与错误率陈述

一个候选为 `effective` 当且仅当：**支柱 1 的调整后 p ≤ alpha** + **支柱 2 的分段一致性与留一法通过** + **完整期数满足下限**。第二节的指标只报告、不否决；后期衰减比同样降级为区间诊断。否则为 `insufficient_evidence`；若稳定地差于随机排序基线则为 `refuted`。族状态为 `effective_factors_found` 或 `insufficient_evidence`。

| 项目 | 口径 |
|---|---|
| 冻结族内族级错误率 | **宣称 ≤ alpha**，条件是：隔离成立、区块自助保持依赖结构、零假设近似枢轴 / 对称、验证期内排序信息系数平稳 |
| 跨轮自适应 / 序贯错误率 | **不宣称**；自适应由隔离消除，不是被检验约束 |
| 共形覆盖保证 | **不宣称** |
| 盈利能力 / 可交易性 | **不宣称**；净价差只是扣了简化成本的可交易性诊断 |
| 无幸存者偏差 | 静态 / 近似成分股名单下**不宣称** |
| 因果性、未来持续、跨市场 / 跨标的池外推 | **不宣称** |
| 小样本 | `T < 24` 自动附 `power_note`：功效低、宽度不能替代独立期数、不拒绝只是弱证据 |

每个肯定结论附中文标签「**横截面有效因子**」、`channel="cross_section"`、断言文本与不宣称项；`spec` 记录全部参数、逐期日期、逐期宽度、数据 / 源码指纹、族规模与逐步下降顺序；同输入同 `fingerprint`。可追溯性是**必要条件，不是替代品**。

**禁止**：为提高功效而提频、缩短调仓间隔、放松显著性水平 / 稳定性门槛 / 最少期数；验证期再搜索或调参；只报表现最好的那个变换；把两类通道的候选混进同一族；以「面向个人研究 / 灵活处理」为由放松统计正确性。

## 六、一手依据（用于识别哪些环节属于统计正确性）

- `microsoft/qlib` `SigAnaRecord` / `PortAnaRecord`：研究单元是横截面，逐期信息系数 / 排序信息系数与多空收益、含开平仓成本的回测；本文的判定对象是「逐期排序信息系数序列」，但**不采用**其「信息系数高即更新最优集合」作为晋升规则。
- Spearman 秩相关作为横截面排序能力度量；排序信息系数在零假设下的抽样标准误约 \(1/\sqrt{N-1}\)（Fisher z 变换同族近似）。
- White (2000) 现实检验、Hansen (2005) 优效检验、Politis & Romano (1994) 平稳区块自助、Romano & Wolf (2005) / Westfall & Young (1993) 最大统计量逐步下降、Harvey/Liu/Zhu (2016) 因子动物园多重检验。
- Dwork 等 (2015) 可复用留出集 / Thresholdout——本文采用「一次性冻结 + 流程 / 信息隔离」设计的直接依据；验证期是冻结日之后的历史样本外数据。
- 机构横截面框架：分组单调性、Fama–MacBeth 稳健 t 值、容量扫描、成本分解、把全部尝试过的变体计入假设族；量化金融报告标准（QFRS, 2026）的时点可计算、滚动因果、禁止全样本标准化。以上**仅作参照系**，个人版裁剪见 `research_process.md` §1.1。

上述均为方法学依据，不构成本项目对其在自适应回路下有效性的背书；保证范围严格限于本文第一节所列条件。
