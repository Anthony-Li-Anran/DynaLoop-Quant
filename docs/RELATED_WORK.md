# 因子探索与漂移适应：价值核查

核查日期：2026-11-13。范围为公式因子发现、动态组合、金融概念漂移和历史回放；这是定向检索，不是穷尽性新颖性证明。

| 已有工作 | 已经解决或研究的内容 | 对本项目的约束 |
|---|---|---|
| [AlphaGen, KDD 2023](https://arxiv.org/abs/2306.12964) | 以组合模型表现为反馈，用强化学习发现协同的公式因子集合 | 自动因子挖掘、奖励驱动生成不是新概念 |
| [AlphaForge, AAAI 2025](https://arxiv.org/abs/2406.18394) | 生成预测网络挖掘因子，按时间表现动态选择、调整组合权重 | 因子挖掘结合动态市场适应已有直接相关工作 |
| [DoubleAdapt, KDD 2023](https://doi.org/10.1145/3580305.3599315) | 用元学习适应数据与预测模型，处理增量股票预测中的分布变化 | 金融概念漂移与增量适应不是首次提出；它的预测器任务与本项目公式搜索不同 |
| [Sleep-like unsupervised replay, 2022](https://www.nature.com/articles/s41467-022-34938-7) | 神经网络中的睡眠式回放缓解遗忘 | 回放思想已有先例，不能将其结果直接推及金融因子搜索 |
| [Wake–Sleep, 1995](https://www.cs.toronto.edu/~hinton/absps/ws.pdf) | 生成和识别网络交替学习 | 本项目是受启发的阶段命名，不是该经典算法的实现 |

## 有意义但未证实的主张

工程目标是可追溯的因子研究工具。方法假设是：在同样候选窗口评价预算下，将近期反馈与历史环境回放结合，可能改善跨时期的因子选择，并避免搜索概率永久集中在过时模板。不是对未来收益或任意漂移的保证。

现有默认生成器是在八类模板中按概率采样，再选择字段与窗口；DEAP 语法生成器是另一可替换实现，不应把默认流程宣传为完整遗传进化。新时间模式保留原模板和表达式接口，研究对象仍是公式因子。

## 必须比较什么

固定因子、均匀随机滚动搜索、自适应近期搜索（Wake）、相同预算的近期历史回放、环境匹配历史回放（Wake–Sleep），另给全模板滚动评价作为计算更多的强参考。不能将这些方法命名为 AlphaGen/AlphaForge/DoubleAdapt 复现；本实验不声称超过这些论文。

有用的证据应来自后续未用于当轮选择的时间段，报告费用后收益、预测关联、切换、预算与不确定性。单次历史窗口中多轮搜索成功不等于跨时间适应成功。2024–2025 数据已在此前实验中被观察；本次历史回放只能称为探索性前向评估。
