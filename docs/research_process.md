## 一、定位：面向个人的研究系统

本项目产出的是**经得起检验的因子结论**，不是资管产品。没有外部资金、客户赎回、合规审计与容量压力，因此机构流水线里由规模与合规逼出来的部分可以裁剪；由统计正确性逼出来的部分**一寸都不能让**。

### 1.1 可裁剪（规模 / 合规驱动）

| 环节 | 个人版处理 | 必须保留的标注 |
| --- | --- | --- |
| L4 容量扫描（不同资金规模下净信息比率） | 可省 | 结论不得外推到任意资金规模 |
| L4 借券 / 融资 / 冲击成本精细建模 | 可用固定基点简化 | 简化参数进 spec；成本与换手仍须显式、毛净并列 |
| L6 制度化上线治理、定期复核、拥挤度监测 | 简化为前向跟踪台账 + 轻量衰减检查 | 不得宣称「已建立上线监控」 |
| L1 商业级时点成分股名单完整重建 | 可用静态 / 近似名单 | **必须标注幸存者偏差未消除**，不得宣称「无幸存者偏差」 |
| L3 多变量横截面检验（Fama–MacBeth 稳健 t 值）作为对照 | 可后置 | 分组单调性、多空分腿、毛净并列须显式报告（描述性，非否决，见基线文档） |
| L0 正式立项与审批系统 | 一页研究笔记即可 | 假设与门槛仍须在看结果前写死并进指纹 |

### 1.2 不可裁剪（统计正确性驱动，个人更该硬）

- 时点数据、防前视、决策与成交分离（下一根 bar 成交）、标签成熟后才评分；
- 因果窗口：所有变换只用 `[t-w, t]`，禁止全样本标准化；
- 预注册冻结：截止日一次性冻结候选族与全部参数并落指纹，冻结文件落盘之后才允许构造验证期数据；验证期是冻结日之后的**历史样本外**数据、一次性评分，隔离是流程 / 信息隔离而非等未来数据到达；**某轮验证窗口被查看即消耗**，再搜索 / 调参必须开新族、用新的未消耗区间，并登记全部前序轮次；
- 族级错误率控制、跨期稳定性、留一法、少于 24 期的功效警示；
- 全部尝试过的配置（含失败的、含各变换版本）计入族规模；全参数进 spec、指纹可复现；
- 分组单调性、多空分腿、对照基线；成本与换手显式、毛净并列；
- 禁止宣称盈利、因果、未来持续、跨轮序贯错误率或共形覆盖保证。

**理由**：机构有内控、风控与同行评审拦着改参数；个人研究没人拦，反复看留出集、事后改假设的诱惑更大，更容易自欺。**能省的是成本，不是证据。**

## 二、频率定位（中低频）

本项目做**中低频**：以日线为数据底座，决策周期在日 / 周 / 月量级，默认持有期 21 个交易日、月度间隔调仓（对应 `research_engine.temporal` 的 `horizon=21` / `interval=21`）。不做日内、分钟级或高频决策，不承诺成交于信号产生的同一根 K 线。

三条由此派生的硬约束：

1. **决策与成交分离**：信号只能用决策时点之前已可得的信息计算，成交发生在下一根 bar；持有期结束、标签成熟后才允许评分。任何「收盘价算信号、同一收盘价成交」的口径一律禁止。
2. **频率进规格**：每次运行必须把标的池、数据频率、持有期、调仓间隔、标签成熟规则写进 `spec` 并纳入指纹。分钟 / 小时级数据可以存在于数据层供其他用途，但**不得混入同一判定族**、不得用来给中低频结论凑样本量。
3. **中低频的统计后果必须正视**：月频一年只有约 12 个独立决策期，单标的时序上十年也只有约 120 期。样本量不能靠提高频率、缩短间隔或放松门槛来凑，那会改变研究对象。功效只能从两处补：**选股通道靠横截面宽度**（每期标的数），**择时通道靠时间长度**（多标的合并估计会改变断言对象，须另立口径）。少于 24 期必须附功效警示（现有 `effectiveness.py` 已实现）。

## 三、双通道设计（2026-11-15 定，本节为核心）

本项目**两条通道并列**，不是只剩选股，也不是把择时判为缺陷。两者都是合法的研究对象，各自给出经得起检验的肯定或否定结论。

### 通道一 · 选股（横截面）

- **问什么**：同一时点，标的池里谁比谁更强（相对排序）。不需要判断大盘方向。
- **数据形态**：每期对标的池全部标的打分，形成一条横截面；标的池与时点成分股口径进 spec。
- **零假设**：无相对排序能力；**对照基线**：随机排序 / 等权；多头与空头两条腿分开报。
- **样本量**：靠每期标的数（宽度），不靠提频。
- **判定（已定稿、已实装）**：权威口径 **[横截面有效因子的统计判定口径](cross_section_factor.md)**，实现 `research_engine/cross_section.py`。逐期排序信息系数相对「无排序能力」零假设，按 \(\sqrt{N_t-1}\) 加权（宽度只降每期测量噪声、不制造独立期数），全族共用时间索引路径的区块自助 + 最大统计量逐步下降 + 跨期稳定性与留一法；评估指标与「门槛 / 仅报告」的划分以 `docs/factor_evaluation_baseline.md` 为准（Qlib `SigAnaRecord` / `calc_ic` / `risk_analysis`、alphalens、`arch` SPA）；分组单调性、多空双腿方向、净价差为描述性诊断，不再一票否决。**零假设与基线不与通道二共用**。
- **状态**：判定层已实装并已认证。L1–L4 横截面诊断、L5 冻结族级检验、只出诊断不出判定的 `diagnose_cross_section` 与两阶段端到端脚本均已落地。**搜索侧已改版**：候选不再来自手写模板，而是 `src/dynaloop/learned_factors/` 本地仿 Qlib 的可训练模型预测（Alpha158 标准特征库 → `LGBModel` → 学得分数），权威说明 `docs/learned_factor_workflow.md`。旧路线的 6 个横截面有效因子（见 `effective_factor_registry.json`）与 1 个族级不显著轮次**降级为历史对照**，不得当作搜索侧能力或交付成果。

### 通道二 · 择时（单标的时序）

- **问什么**：这只标的接下来方向 / 关系如何（绝对方向）。
- **数据形态**：每期一个标量预测 vs 一个标量目标；候选绑定单个标的代码。
- **零假设**：逐期损失差分不胜过零预测与历史均值两条基线。
- **样本量**：靠时间长度；月频下天然稀疏，必须正视低功效。
- **判定**：**已实装**，权威口径 `docs/effective_factor.md`，实现 `research_engine/effectiveness.py`（因果隔离 + 共用时间索引路径的区块自助法最大统计量逐步下降 + 稳定性与留一法）。
- **状态**：已实装，是本阶段现有代码主体。`temporal.py` / `effectiveness.py` / `catalog.py` 都属于这条通道，**不是白写，也不是要推倒重来**。

### 为什么两通道必须分开判定

| | 通道一 选股 | 通道二 择时 |
| --- | --- | --- |
| 断言 | 相对排序有稳定信息 | 绝对方向 / 关系稳定可重复 |
| 零假设 | 无排序能力 | 不胜过零预测与历史均值 |
| 对照基线 | 随机排序 / 等权 | 零预测 / 历史均值 |
| 样本结构 | 每期 N 个横截面观测 | 每期 1 个标量观测 |
| 功效来源 | 宽度（每期标的数） | 长度（决策期数） |

零假设、基线、样本结构全不同。**把两类候选扔进同一个判定族、共用一套族级错误率控制，族规模混算、零分布不再对应任何一个断言，控制即失效。** 因此：各自预注册、各自冻结、各自晋升、各自出带指纹的证据条目。

### 命名与证据标签

- 输出结论**必须带通道标签**：「横截面有效因子」/「择时有效因子」；禁止不带标签地统称「有效因子」。
- 现有 `effectiveness.py` 的 `effective` 终态自本规范起**专指通道二**；**通道标签已落地**：`channels.py` 统一提供常量、中文标签、断言与不宣称项，`evidence_from_report` 产出带指纹的规范化证据条目，`enforce_channel` 对混族硬拒绝，两份判定器的报告、逐候选结论与 `spec` 均写入 `channel` / `channel_label` / `assertion` / `scope_limit`。
- 两类证据不得互相外推：择时结论不能写成对股票池的认证，选股结论不能写成对单只标的进出时点的认证。
- **合成**（把两类证据变成交易决定）不在 Part A，交给 Part B；Part C 执行。与三段分工一致，A 未达成前不声称 B / C 交付。

## 四、机构流水线七层（个人版裁剪标注）

按投研机构的研究流水线分层，而不是按技术组件分层，用来识别每层属于正确性还是规模副产品。上游未交付，下游不得开始，更不得用下游结果反推上游有效。

**L0 研究立项与假设登记**（不可裁剪）
经济逻辑、预期方向、预期持有期、预期失效模式、分析计划与判定门槛，在看结果之前写死并纳入指纹；禁止事后改假设。个人版允许一页研究笔记代替正式立项系统。

**L1 时点数据底座**（核心不可裁剪）
不可变数据快照 + 数据指纹；每条记录带「可得时间」而非仅「事件时间」；截断测试、安慰剂测试、额外滞后测试作为自动化门禁。商业级历史成分股名单重建可按 1.1 简化，但必须标注幸存者偏差未消除。复权、停牌、涨跌停、退市结算显式处理。

**L2 因子实现与标准化**（不可裁剪，可简化实现）
横截面去极值、标准化 / 排名、方向对齐；行业与市值中性化；保留原始 / 排名 / 去极值 / 中性化各版本，不能只留「表现最好的那个变换」。所有变换窗口必须因果（只用 `[t-w, t]`），禁止全样本统计量。个人版可用简化中性化，但**不得整段跳过**且须在 spec 标注所用版本——否则「有效」可能只是已知风格暴露的伪装。

**L3 单因子诊断**（核心不可裁剪）
覆盖度、缺失率、分布、自相关；排序信息系数及其衰减曲线；分组（五分位 / 十分位）收益单调性，多头与空头两条腿分开报；与已知因子的相关性 / 冗余度。多变量横截面检验（Fama–MacBeth 平均斜率 + 异方差自相关稳健 t 值）作为对照，个人版可后置。**不得一上来就跑组合优化器**。

**L4 组合层现实化**（成本与换手不可裁剪，精度可简化）
至少三种实现并列：等权分组、市值加权分组、成本感知打分组合。换手、佣金、印花税、毛 / 净结果必须显式，不得用「忽略不计」带过；A 股特有约束（T+1、涨跌停、停牌不可交易）必须进撮合语义，属结论正确性、不裁剪。容量扫描、借券融资、冲击成本精细建模按 1.1 简化。

**L5 冻结样本外与晋升门禁**（全链最不可裁剪，本项目统计学主场）
预注册冻结候选族与全部参数（冻结文件先落盘）→ 在冻结日之后的历史样本外数据上一次性验证 → 对整族做抗数据窥探的族级检验 → 跨期稳定性与可重复性 → 与对照基线比较 → 事先写死的晋升标准。对照基线至少包含：随机滚动搜索、仅唤醒、等预算近期回放、全量滚动参考。**两条通道各自独立执行本节**。

**L6 上线后监控与复核**（制度化治理可简化）
个人版简化为前向跟踪台账（模拟撮合 / 纸上跟踪）与轻量衰减检查。历史样本外通过不等于未来持续有效；任何结论都不得宣称未来持续。

## 五、贯穿全链的治理规则

- **可追溯**：数据来源与指纹、时点口径、公式、逐期样本外表现、全部尝试过的配置（不只是幸存者）、已知限制，全部进 `spec`。实验计数自动化，让「我到底试了多少次」可查询而非靠回忆。
- **可复现**：同 seed + 同 spec → 同指纹、同结果；数据快照不可变，任何上游变化发新版本。
- **可证伪**：每个结论必须写明它在什么条件下会被推翻，以及不宣称什么。
- **分层门禁**：L5 的晋升是各通道「有效」断言的唯一出口；L3 的信息系数、L4 的净收益都只是诊断，不能单独构成晋升依据。
- **通道隔离**：两条通道的族、冻结、检验、晋升、证据条目全程分离；不得合并、不得互相外推、不得共用族级错误率控制。
- **裁剪留痕**：凡按 1.1 裁剪的环节，必须在报告里写明裁了什么、为什么、结论因此不能外推到哪。
- **口径与三段分工的衔接**：Part A 覆盖 L0–L5 的两条通道（L4 在 A 内作为可交易性诊断，真正的组合优化与两类证据的合成本质上属于 Part B）；Part C 承接 L6 的执行与风控。A 未达成前不得声称 B / C 已交付。

## 六、现状对照（如实标注，不得抹平）

### 通道二已实装（不是缺陷）

`research_engine/temporal.py` 的 `FactorTape` 吃一维有序 bar 序列，`open/close/targets` 都是一维数组；`FactorFrame` 产出每个日期一个标量因子值；`screen()` 比较「标量预测 vs 下一期标量收益」的均方误差。`research_engine/effectiveness.py` 的 `VerificationRow` 是「一个决策期、一个候选、一个标量预测、一个标量目标」；`FrozenCandidate` 带 `symbol` 字段。

这些**正是通道二的数据形态**，是合法且已实装的研究对象。现有 `effective` 终态严格说是「该标的的择时关系在冻结窗口上稳定可重复」，**不是横截面有效因子**——这是术语与适用范围的约束（见第三节），不是代码错误。

### 通道一已实装（不是推倒现有实现）

`research_engine/cross_section.py` 的 `CrossSectionSlice` 是「一个决策期、一个时点标的池、每标的分数与成熟标签」；`_check_isolation` 强制时点特征、决策与成交分离、标签成熟后评分、族成员一致、宽度下限与缺失标签不得补零；`_period_diagnostics` 产出分组超额收益、多空分腿、换手、成本、毛净并列；`assess_cross_section` 出 L5 终态，`diagnose_cross_section` **只出 L1–L4 诊断、结构上不能出结论**。权威口径见 `docs/cross_section_factor.md`。

真实数据底座复用既有 qlib 归档（沪深 300/500 历史成分、月末决策、下一根 bar 成交、次月末标签成熟），`experiments/factor_stream/cross_section_assessment.py` 构造出 259 个月末横截面。旧版以「冻结前可得、可能被回看」为由标记 `WITHHELD` 只出诊断，属口径错误。现按历史样本外预注册执行完整 L5：搜索期自由挖掘 → 截止日一次性冻结族 / 参数 / 成本 / 晋升规则并落指纹 → 冻结日之后的历史数据一次性评分。多轮独立预注册、消耗窗口与结论见 `experiments/factor_stream/preregistered_*`；跨轮序贯错误率不宣称。

### 搜索侧主线改版（2026-11-15）

Anthony 否决手写模板 + 枚举筛选路线，要求「原模原样按 Qlib 来搭」且「参考模仿自己本地写」。现已落地 `src/dynaloop/learned_factors/`：本地仿写数据提供者、Qlib 算子语义求值器、158 项 Alpha158 标准特征库、`DataHandlerLP` / `DatasetH` / `LGBModel` 四环节编排，模型预测即学得因子；两阶段预注册脚本 `preregistered_learned.py` 保持「冻结文件先落盘、验证期数据才构造」。**不 import `pyqlib`**，逐层可替换，后期可改。详见 `docs/learned_factor_workflow.md`。

旧路线（15 个手写模板、`factor_search.py` 枚举筛选、DEAP 文法随机采样、6 个已认证因子）降级为历史对照，不得当作研究能力或交付成果；统计保证只保护结论，不证明搜索侧能力。第五层认证出口、三支柱与不可绕过清单**一律不变**。新主线真实数据一次性冻结验证已出结论：58 期样本外、族级 p=0.0060、学得因子判定「横截面有效因子」（见 `preregistered_learned_20261115/certification.json`）。

### 个人版取舍下仍需补齐

- 商业级时点成分股重建（现标 `approximate`、幸存者偏差未消除，公告可得性 / 退市结算 / 公司行动未完全核实）；
- 行业 / 市值中性化、去极值、冗余度与容量扫描；
- A 股撮合约束进 L4（T+1、涨跌停、停牌；当前成本模型是简化的个人版，且明确不建模 bar 级撮合）；
- L6 前向跟踪台账与轻量衰减检查；
- 因子自相关（Qlib `pred_autocorr` / alphalens 因子秩自相关）与纽维–韦斯特修正的信息系数 t 值已按上游口径实装于 `evaluation_metrics.py`，二者**严格只作描述性报告**，不进族检验、不进稳定性判据、不进终态，也不进指纹；口径与滞后阶规则见 `docs/factor_evaluation_baseline.md` §7。

### 我们的主场（不削弱）

L5 的**因果隔离**（截止日一次性冻结族与全部参数并落指纹，冻结后才构造冻结日之后的历史样本外数据，把自适应分析难题用设计消除）、**族级错误率控制**（平稳区块自助法全族共用时间索引路径 + 最大统计量逐步下降）、**跨期稳定性与留一法**、少于 24 期自动附功效警示，加上指纹、全参数 `spec`、不可变证据产物、不可覆写输出目录、下一根 bar 成交、标签成熟后才评分，以及与四类对照基线的比较和成本敏感性账本——这些已经实装且强于多数开源实现，**两条通道各自独立执行**。通道一与两通道标签已补齐，评估指标与门槛已按 `docs/factor_evaluation_baseline.md` 对齐 Qlib / alphalens，改造重点转向数据底座质量与搜索侧，**不是削弱 L5**。

### 实证口径不变

2026-11-14 的真实数据实证只覆盖一只创业板指数基金（未复权日线）、9 个决策期、3 个冻结候选，族级 p = 0.9840、有效 0 个（2 个证伪）。其结论只对这一范围与通道二有效，不得外推到股票池、市场或通道一。2026-11-15 重构 `effectiveness.py` 转调共用数学工具后，该实证的族级 p 与指纹**逐位复现**，新产物补上「择时有效因子」标签。

2026-11-15 的 259 个月末横截面诊断仍是**描述性证据**，不得读成有效因子；带错误率的结论只来自各轮 `preregistered_*` 产物里的 L5 报告。每轮窗口被查看即消耗，前序轮次与消耗窗口在冻结文件里逐轮登记。

## 七、不可绕过清单（后续实现必须遵守）

1. 禁止把「单标的时序预测改善」写成「横截面有效因子」。
2. 禁止用高信息系数、排行榜名次、单次留出通过或描述性区间替代 L5 晋升门禁。
3. 禁止为提高功效而提高数据频率、缩短调仓间隔或放松显著性水平 / 稳定性门槛 / 最少期数。
4. 禁止验证期再搜索或调参；改一次开新族、用新的未见区间。
5. 禁止只报「表现最好的那个变换」；所有尝试过的配置计入族规模。
6. 禁止把毛收益当结论；成本与换手必须显式，净结果同时报。
7. 禁止宣称盈利、因果、未来持续、跨轮序贯错误率或共形覆盖保证。
8. **禁止把两条通道的候选混进同一判定族、共用族级错误率控制、或把一类结论外推成另一类。**
9. **禁止以「面向个人研究 / 灵活处理」为由放松统计正确性门槛**（时点数据、预注册冻结、族级控制、稳定性、成本与换手显式）。
10. **禁止用已被本轮冻结之后查看过的窗口重复出结论**：验证窗口一旦被查看即消耗，再搜索必须开新族、用新的未消耗区间，并登记前序轮次与消耗窗口；跨轮序贯错误率不宣称。历史样本外预注册是合法且默认的认证方式，**禁止**以「数据不是未来真实到达」为由拒绝出 L5 结论。
11. **禁止靠升配置版本号引入附加描述性指标**：两判定器的 `schema_version` 会经 `config.to_dict()` 进入冻结报告指纹，升版本会让全部历史指纹漂移。新增纯报告指标必须保持版本号不变、不进指纹，且必须先在 `docs/factor_evaluation_baseline.md` 登记上游依据与「仅报告」身份；新增任何晋升门槛同样须先登记，**禁止自创阈值**。

## 八、工程默认值（2026-11-15 定稿；Anthony 授权 AI 全权决定）

以下是**工程默认值，不是统计门槛**。任何一项都不改变已冻结轮次的结论，只对新开的预注册轮次生效；改动必须写进该轮的 `spec` 与冻结指纹。定稿依据是「不引入无法核实的数据、不改变断言对象、不越界到 Part B」，不是从现有实现倒推。

| 项 | 定稿 | 理由 | 可回退性 |
| --- | --- | --- | --- |
| 标的池形态（仅通道一） | 默认**指数成分历史区间池**（`point_in_time`，如实标注 `approximate`、幸存者偏差未消除）；**全历史有价格标的池**（`all_listed`）仅作并列对照，其结论不得标成时点有效 | 现有归档只支持这两种口径；三只指数基金宽度仅 3、功效不足；编造商业级时点成分股等于制造无法审计的数据 | 换池即开新族、新窗口并登记；已实装双池参数 |
| 默认调仓节奏 | **月频**：月末决策、下一根 bar 成交、次月末标签成熟，默认持有 21 交易日，年化因子 12 | 与已有三轮实证、Qlib 月频 `risk_analysis` 口径一致，避免混频率污染族级检验 | 周频只能作为独立对照轮，须重新预注册并改年化因子；禁止在同一族内混用 |
| 通道二多标的合并估计 | **Part A 阶段不允许** | 合并会把断言对象从「单标的时序」变成面板，零假设与基线都要另立；当前判定器只收单标的时序行，允许合并等于悄悄改口径 | 若将来要做，必须新建第三条判定族、单独文档与单独族级错误率，不得复用现有族 |
| A 股撮合参数 | 维持简化个人版成本（双边佣金、卖出印花税、双边滑点、默认不可卖空），并在 `spec` 与不宣称项标注**未建模** bar 级撮合（涨跌停、停牌、整手、最低佣金）；T+1 已由决策与成交分离体现 | 无可靠逐笔 / 涨跌停数据，填参数就是自创标准；这些约束属 Part C 的撮合语义 | 成本模型已参数化，接真实规则只需新轮预注册，不得回头改已冻结轮 |
| L4 在 A / B 的边界 | Part A 只做**描述性**可交易性诊断：毛净并列、换手、成本敏感性、分组与分腿；权重、组合优化、约束与执行全部归 Part B | 职责单一，避免研究器越界做组合优化 | 接口只读，Part B 自行决定消费方式 |
| A→B 接口形态 | 唯一入口是 `channels.py` 的带通道标签、带指纹的 `FactorEvidence`；只读索引是 `experiments/factor_stream/effective_factor_registry.json`。Part B **不得**直接读判定器内部对象，也**不得**把两通道证据合并成一个族 | 通道隔离要一路保持到消费端；注册表把断言、证据路径与不宣称项一起交付 | 接口为纯数据契约，扩展字段向后兼容 |

**两通道证据在 Part B 的合成方式**属于 Part B 的设计决定，不在 Part A 定稿；本节只固定「合成时不得合并族级错误率」这条硬约束。

## 九、一手依据（2026-11-15 核实）

以下来源用于**识别哪些环节属于统计正确性**，机构标准在此作参照系而非合规要求：

- `microsoft/qlib` 官方文档与工作流：研究单元是横截面（每期对标的池全部股票打分），`SigAnaRecord` 产出信息系数 / 排序信息系数与多空收益，`PortAnaRecord` 产出含开平仓成本的回测与风险分析；提供时点数据库与 `qrun` 全流程。
- 机构横截面研究框架：分组单调性、Fama–MacBeth 回归与异方差自相关稳健 t 值、基准归因、容量扫描、成本分解、把全部尝试过的变体计入假设族（Harvey/Liu/Zhu 2016）、模型锁定后按时间顺序样本外验证。
- 时点数据与前视偏差：量化金融报告标准（QFRS, 2026）要求每个特征在决策时点可计算、滚动窗口严格因果、禁止全样本标准化；截断测试、安慰剂测试、额外滞后测试、时点连接审计为常规门禁。
- 数据窥探：White（2000）现实检验、Hansen（2005）优效检验、区块自助法保留序列相关、预注册与不可变实验日志使检验次数可查询。
- 自适应分析：Dwork 等（2015）可复用留出集 / Thresholdout——反复查询会让留出集本身过拟合，是本项目采用「一次性冻结 + 流程 / 信息隔离」设计的直接依据；本项目的验证期是冻结日之后的历史样本外数据，不要求物理上未来到达。
