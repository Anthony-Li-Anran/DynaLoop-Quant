一手证据支持的结论

1. 在「预测市场」这一层，LLM 基本是冗余的。价量数据是低语义数值序列；正式综述报告里 GPT-4o、DeepSeek-V3、Qwen3-32B 表现基本持平；RLVR 的 spurious-reward 实验显示，用与正确答案无关甚至错误的奖励训练，数学任务仍能大幅提升，说明 RLVR 更多是能力激发而非知识注入。起作用的是搜索结构、受限文法与可验证反馈，不是模型里的金融世界知识。

2. 赛道工程成熟，但样本外优势缺乏统一证据。FactorBench 在统一协议下回测约 5,000 个 AI 挖掘因子、跨 5 个市场：没有任何范式稳定胜出；中性化后多数方法的残差 IC 归零或翻负；多空收益远低于多头收益，说明多头利润主要是市场 beta；2016 年手写的 Alpha101 在各层级仍具竞争力。

3. 「怎么教」的成熟答案是可验证奖励，不是金融知识灌输。模型输出受限 DSL 表达式 → 编译执行 → 在固定窗口上算 IC/RankIC 或回测指标 → 该数值直接作为 reward，不经过 LLM 自评或人类偏好。GRPO 用组内相对优势、无需 critic，适合稀疏标量奖励。

4. 金融的「可验证」与数学/代码不是同一种可验证。金融奖励可计算但内禀嘈杂，r = r* + ξ 且噪声方差远大于信号；按 n₉₅ = ⌈(1.96σ/α)²⌉，判定一个 modest edge 需要数千笔样本（约数百交易日），而数学题 n₉₅ = 1。直接用 P&L 当 verifier 会退化为 reward hacking。

5. 项目的三条技术支柱在文献里共享同一个失效结构。Wake-Sleep 的 sleep 相用生成模型的幻想数据训练识别网络（Hinton et al. 1995，Science）；循环深度里多数 token 第一次迭代已正确、后续迭代反而改错（Think-at-Hard，ICML 2026）；自进化闭环用自身输出递归训练会不可逆地丢掉分布尾部（Shumailov et al. 2024，Nature）。三者都是「内部生成的信号训练无法直接监督的模块」，修法也一致：注入回路不可触碰的外部锚点，并给门控留弃权语义。

6. 项目里的「Wake-Sleep」目前是结构类比，不是算法实现。PROJECT.md 写的是「以 Wake-Sleep 闭环在共形校准的回测代理模型与真实市场验证之间迭代进化」；Hinton 1995 的两相更新的是同一个 Helmholtz 机的两组权重，两者不同。文献里最接近项目措辞的是 Dyna / world model（代理里练、真环境验）与 DreamCoder（醒时解题、睡时压缩出抽象），不是原始算法本身。

判断（非定论，供讨论）

项目已确认的定位是「不是用 AI 做量化，是用量化做 AI 研究」：量化是考场，研究对象是自主科研模型如何避免自进化偏差——模型在自己产出的有偏反馈上加速自欺。因此 LLM 在预测层冗余恰是这个考场的优点：反馈是数值的、可复现的、不依赖 LLM 自评，才能把「模型学会了」与「模型在骗自己」分开。现有框架里 LLM 兼任 evaluator（QuantAgent 的 judge、AlphaAgent 的语义对齐检查）正是自评，属于要被卡掉的虚假反馈来源。

Anthony 在 2026-11-10 提出：统计与不确定性怎么定义，可能要等模型做出来再决定。本次调研支持这一判断——文献里至少存在三种互不等价的「保证对象」：单个因子的显著性、整个发现过程的任意停时错误控制、以及策略-奖励耦合造成的自我确认偏差。选哪一个取决于研究循环怎么构造，先定统计口径等于预设研究对象。

3.2 研究主体层：冗余性反而构成考场优势

项目内部已确认口径（AGENTS.md §1.1、PROJECT.md、2026-11-10 项目日志，D）：方向是 QUANT 与 AI 的交叉，学术意义优先于 PnL，研究 + 工程双修；本质不是「用 AI 做量化」而是「用量化做 AI 研究」，量化是考场，研究对象是自进化偏差；标语为「统计保证的 Wake-Sleep 自进化量化研究闭环」。

在这个定位下，LLM 不是市场预测器，而是研究主体：提出假设、写表达式、读取反馈、修正。市场提供的是硬反馈——数值、可复现、不依赖评判者的自然语言意见。正因 LLM 无法靠语言先验「读懂」市场，反馈里才不会混入世界知识，才能把「模型真的学会了」与「模型在自己骗自己」分开。

04「要怎么教模型去做这件事」

4.1 教什么：不是金融知识，是「产出可执行假设并接受外部裁决」

成熟的训练形态是 RLVR / 可验证奖励：模型输出受限 DSL 表达式 → 编译器/Realizer 变成可执行代码 → 在固定数据窗口上算 IC / RankIC / 回测指标 → 该数值直接作 reward，不经过 LLM 裁判或人类偏好打分。冷启动（SFT / 种子因子库）只用来学 DSL 语法与合法输出格式，不用来学市场。

GRPO（DeepSeekMath 2024 提出）去掉 PPO 的 critic：对同一 prompt 采样一组 G 个响应，用组内均值与标准差构造相对优势

Aᵢ = (rᵢ − mean(r₁…r_G)) / (std(r₁…r_G) + ε)

再以 PPO 式裁剪目标加对参考模型的 KL 惩罚更新。奖励为 0/1 二值时，组内优势直观等价于「同伴里有几个也做对了」；实践中省一份 critic 显存。IBM Research（arXiv:2503.06639，B）证明该归一化可化约为加权对比损失，具有「成功放大」性质。

4.2 三条已知失效路径

4.3 金融场景为何不能直接照搬

Trade-R1（arXiv:2601.03948，B）给出最清晰的诊断：金融奖励可验证但内禀嘈杂，r = r* + ξ 且 Var(ξ) ≫ r*；于是「正确决策亏钱、错误推理赚钱」成为常态，标准 RL 会退化为动量机器，为历史赢家编造理由（hallucinated rationales）。该工作不以 P&L 直接作奖励，而引入过程级三角一致性（证据↔推理、推理↔决策、证据↔决策）作噪声过滤器，等于承认 P&L 不是合格的 verifier。

噪声地板的量级

95% 置信判定一个真实 edge 所需样本 n₉₅ = ⌈(1.96σ/α)²⌉。以日波动 3.46%、单笔 edge 0.1% 计约需 4,598 笔样本（日 20 笔 ≈ 230 天）；数学/代码任务 n₉₅ = 1。这与 §5.2 的「≈500 交易日认证等待」是同一统计事实的两种表述。

05统计可信度：整条链条最薄弱处

本节直接回应 Anthony 的口径「统计与不确定性怎么定义，可能要等模型做出来再决定」：文献里已经存在数种互不等价的「保证对象」。

5.1 Agent 循环同时违反三个经典假设

Propose, Don't Judge（arXiv:2609.27051，B）指出，现有 agentic 系统让同一个 agent 提议、回测、筛选、退役全包，而它们使用的 t 统计量、IR、甚至 deflated Sharpe 都假设检验批在事前固定：

Agent 行为被破坏的假设
读到判决再改，直到通过可选停止（fixed-sample 检验失效）
把幸运因子的近似重复一起提交多重检验（批量校正假设检验数固定）
学习评估器奖励什么验证器在环适应
在评估期上训练知识截断泄漏

事前计算的多重检验校正需要「事前已知的提议过程」，而学习型 agent 没有这样的过程。因此固定批量校正在数学上不适用，只能靠 anytime-valid（序贯）推断。

5.3 另一类对象：自奖励导致的自我确认偏差

《Breaking the Self-Confirming Loop》（ICML 2026 / arXiv:2510.08977，A）研究 self-rewarding RL（RLIR）：reward 与策略置信度强耦合，模型对高置信度错误过度奖励，形成自确认循环，偏差随训练累积并向 over-reward 漂移。文中给出三个度量：

  • ρ_noise — 奖励估计偏差的绝对幅度（相对 oracle reward）
  • ρ_selfbias — 策略-奖励耦合强度，即环路对偏差的放大程度
  • ρ_symbias — 过度奖励 / 奖励不足的不对称偏斜

其缓解方案 RLER 用多模型集成奖励与 disagreement-aware 采样降低耦合。另有 MIT CSAIL 的 RLCR（经二手报道，C）指出标准 RLVR 会让模型的置信校准变差，需在奖励中加校准项（Brier score）。这两条线索把「自进化偏差」从口号变成了可度量的量。

06Wake-Sleep：原始算法、已知缺陷与现代回归

PROJECT.md 的原话是「以 Wake-Sleep 闭环在共形校准的回测代理模型与真实市场验证之间迭代进化」。本节先还原算法本身，再看这个措辞在文献里对应什么、不对应什么。

6.1 1995 年原始算法的准确形态

Hinton, Dayan, Frey & Neal, The "Wake-Sleep" Algorithm for Unsupervised Neural Networks, Science 268(5214):1158–1161（1995-05-26，DOI 10.1126/science.7761831，A）。对象是 Helmholtz 机：同一堆随机二值神经元之间有两组权重，自下而上的 recognition 与自上而下的 generative。原文摘要给的定义是：

相位由哪组权重驱动训练数据从哪来更新哪组权重
Wakerecognition（bottom-up）真实观测逐层推断出隐表示generative，使其更容易重建被激活的下层活动
Sleepgenerative（top-down）从先验采样、自上而下生成的幻想样本（fantasies）recognition，使其在幻想输入上重现上层激活

关键是被更新的恰好是「驱动方」的对偶：两相互为对方提供训练目标，因此不需要外部教师信号。原文的优化目标是最小描述长度（MDL）——一个「先把隐表示发给接收者、再发输入与重建之差」的通信博弈，而不是今天教科书里的 ELBO。局部 delta 规则即可更新，不需要跨层反传，这是它当年被看重的生物学动机。

两个常见误传

其一，「wake-sleep 优化 ELBO」不准确：ELBO + 重参数化的表述属于 VAE 一脉（Kingma & Welling, 2013）；VAE 恰恰是把两相融合成单一目标才取代了它。其二，「已被证明收敛」需收窄：Ikeda, Amari & Nakahara（NIPS 11, 1998）给的是特定网络结构、学习率与随机单元假设下的收敛结果，不是任意深度的通用保证。

6.2 病灶：识别网络的训练分布由「还不够好的模型」供给

Dayan 等人的《Varieties of Helmholtz Machine》（A，多伦多大学原文 PDF）在方法章节直接写明：sleep 阶段 recognition 模型并不是按自由能 F 的梯度更新，而是按

KL[ P_true(h|d) ‖ Q_rec(h|d) ]，其中 d ~ p_generative(d)，而不是 d ~ p_data(d)

KL 不对称，方向反了，而且数据来自生成模型自己的分布而非真实分布。后果是结构性的：生成模型越不准，识别网络被训练去反演的世界就越偏；两者互为监督，偏差会自我强化。Frey, Hinton & Dayan（NIPS 8, 1996）那篇《Does the wake-sleep algorithm produce good density estimators?》连标题都是对自身的质疑。

修正路线有两条，都不是靠「多睡几轮」：

6.5 「共形校准的回测代理」：最接近的外部工作与它的硬边界

没有检索到「金融回测代理 + 共形校准 + 自进化闭环」的直接合流工作。最接近的是科学计算里给代理模型（surrogate）加共形误差带：

  • Gopakumar et al., Uncertainty Quantification of Surrogate Models using Conformal Prediction（arXiv:2408.09881，v1 2024-08 / v3 2026-01，A）：模型无关、逐单元格校准、保留张量结构、给有统计保证的边际覆盖；在流体、磁流体、天气、聚变诊断上，跨架构 / 训练机制 / 输出维度都得到有效误差棒，校准只需数秒到数分钟，且据摘要在 OOD 物理域上仍保持覆盖。作者自己在摘要末尾写明前提：只给边际而非条件覆盖，且假设校准数据与测试数据可交换。
  • NeurIPS 2026 Conformal Prediction Under Physical Constraints for Scientific Surrogates（会议页摘要，B）：分布漂移下用自适应机制放宽区间。但它给出的负面结论更值得记——该检测器在天气 shift 上能恢复覆盖，在分子动力学与药代 shift 上只能部分恢复；作者称这是 hard limit 而非实现缺口：「输入空间的信号被要求回答一个关于代理误差的认知性问题」。
  • region-wise conformal 的 sim-to-real 认证（研究构想页，C）：按状态空间分区、逐区给代理误差做条件共形认证，只在「不可信区」采真实数据。方向上正是「代理 / 真实」的统计化分工，但该页自述为待验证构想，不是已发表结论。
必须写清的边界

共形预测能给的是「代理误差在校准分布内多大」的诚实刻度，不能把代理产出的反馈升级成真实反馈：金融时序的 regime shift 直接破坏可交换性；边际覆盖不等于「这一只票、这一段行情」的条件覆盖；且共形只校准误差带，不证明代理在从未见过的区域是对的。因此 sleep 阶段的反馈仍然是自产的，统计闸门要卡的偏差对象并没有因为加了共形而消失。

Dehghani 等：把 N 个独立层换成一个共享块迭代 T 次，加 position + timestep 二维坐标嵌入，用 Graves 的 ACT 让每个位置自行决定何时停机。固定步数时等价于层间权重绑定的多层 Transformer；在「内存充分」假设下论证计算通用性（Turing complete）。bAbI / LAMBADA / 算法任务显著优于同规模 Transformer。

2025-02

8.1 三条不能越过的边界

避免把假设写成事实

① 标语是类比，不是实现。「Wake-Sleep 闭环」目前只是 PROJECT.md 的一句话；它对应的外部结构是 Dyna / world model 与 DreamCoder 式库学习，不是 Hinton 1995 算法；src/ 里零实现。

② 共形校准不等于代理可信。它给的是校准分布内的边际误差带，前提是可交换性；金融 regime shift 下该前提不成立，且代理在未见区域的错误是认知性的，输入空间信号未必能检测（NeurIPS 2026 那篇自述的 hard limit）。加共形不会把自产反馈变成真实反馈。

③ L1 的收敛不解决 L3 的可信度。隐状态稳定、循环停机可靠，都只是计算层性质；发现过程是否在任意停时下不失真，是 §5 的统计问题。两套判据不能互相替代。

8.2 与「统计定义等模型做出来再定」的关系

§5.5 已列出三种互不等价的保证对象（单因子显著性 / 发现过程的任意停时 FDR / 反馈回路的自我确认偏差）。本版再添一个维度：被保证的信号究竟来自真实环境还是代理。若 sleep 阶段的反馈来自共形校准的回测代理，那么「代理误差带的覆盖率」与「发现过程的可信度」是两个不同的量，前者是后者的输入，不是后者的替代品；这一区分依赖循环实际怎么构造——wake/sleep 谁产生候选、谁给裁决、代理多久用真实数据重校准一次。

因此 Anthony 在 2026-11-10 的判断「统计与不确定性怎么定义，可能要等模型做出来再决定」在文献侧依然成立，而且比第一版更明确：统计对象是回路结构的一个函数。回路未成形时先选工具，等于把研究对象预设掉。本报告到此为止，不给统计模块设计、不排模块顺序。
