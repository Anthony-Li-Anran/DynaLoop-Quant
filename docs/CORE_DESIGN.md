# DynaLoop 核心设计

更新：2026-11-15（三次修订：个人研究版 + 双通道，通道一已落地）。当前主线由下述最新定位覆盖，含 Part A / B / C 三层角色分工、中低频定位与选股 / 择时双通道；后面的神经路径说明保留为历史记录。

## 当前主线：产出高质量的有效因子（「身体」）

**本阶段的交付物是有效因子本身，不是关于因子的研究报告。**（Anthony 2026-11-14 定调）

### 分层，不要把阶段目标当成终局

- **终局**：可训练、自适应、边推理边训练的决策「大脑」，配醒睡机制与统计保证；天生不是固定参数的死模型。
- **本阶段**：先造「身体」——高质量公式因子的自动研究能力，为后续决策提供可验证的感知与执行基础。产出物供后续预测器和交易模型直接消费。
- **关系**：神经大脑**暂缓实现，不是放弃该方向**；其代码、实验报告与测试全部保留，见下文历史说明。新闻/大模型信号提取暂缓。

### 三段角色分工（Anthony 2026-11-14 定）

按「投研团队里的角色」切分，而不是按技术组件切分。三段有明确先后：先 A，再 B，再 C。

**Part A｜量化研究员（当前阶段，即「身体」）**
- 职责：**稳定产出高质量有效因子的自进化研究器**；交付物是有效因子本身，不是研究报告。
- **不强制醒睡机制**；优先复用成熟开源最佳实践，不重复造轮子。一手参照：`microsoft/qlib`（数据处理、因子表达与回测基建，本项目阶段 1 的算子表达式已按其同名算子对齐）、`microsoft/RD-Agent` 中的 RD-Agent(Q)（NeurIPS 2025，arXiv 2505.15155；假设生成 → 代码实现 → 真实回测 → 反馈分析的自动研究闭环，含因子去重、多臂老虎机调度、Qlib 回测与信息系数 / 排序信息系数评测）。
- 本阶段**唯一必须交付**的部分。A 未达成「稳定产出有效因子」之前，不把 B / C 算作已交付。

**Part B｜量化策略（后续阶段）**
- 参照 `shiyu-coder/Kronos`（AAAI 2026，MIT 许可）：分词器把开高低收量量化为分层离散词元，再用仅解码器的自回归变换器预训练，覆盖 45 家以上交易所约 120 亿根 K 线；开源 mini / small / base 三档权重，最大档未开放；仓库自带 Qlib 微调脚本。
- Anthony 的动机：第三方独立样本外评测（2026）报告其方向准确率接近随机、扣除交易成本后无收益，建议当作研究基线或合成路径生成器，而非可直接交易的策略。**须如实标注：这是第三方评测，不是官方结论，也不等于全面复现**；但它足以说明「只靠价格序列的基础模型」信号不足。
- 因此 **Part A 的两通道带标签证据作为额外信息注入 Part B**，补上单靠行情序列缺失的横截面关系信息与择时证据。这是三段分工里最关键的接口；两通道的合成在此层完成，不在 Part A。
- **醒睡机制与组合优化放在这一层**，不在 Part A。若此处引入合成市场状态训练，生成器偏差的统计控制同属本层。

**Part C｜量化交易员（后续阶段）**
- 拿到 Part B 的交易信号，做交易决定与判断：下单、仓位、风控、成本。
- 项目内「实盘」= 模拟撮合（paper trading），不是真钱交易。

**层间接口（2026-11-15 定稿 A→B；B→C 留待 Part B 设计）**
- **A → B 已定稿**：唯一入口是 `channels.py` 的 `FactorEvidence`（带通道标签、断言、不宣称项与指纹），只读索引是 `experiments/factor_stream/effective_factor_registry.json`。Part B 消费的是**带有效性证据的因子库条目**，不只是因子数值；不得直接读判定器内部对象，不得把两通道证据合并成一个族或共用族级错误率。
- **B → C 待定**：信号形态（方向分数 / 目标仓位 / 组合权重）与决策边界属 Part B 设计，不得由现有实现倒推。
- 统计保证贯穿三段，但落点不同：Part A 是「有效」的判定口径，Part B 是生成器偏差控制，Part C 是执行与成本的诊断。

### 「有效因子」的验收含义（单轮已达成；跨轮稳定不宣称）

在未来未参与搜索的数据上，相对零预测与历史均值有**稳定、可重复的预测关系**；结论有明确的统计依据，能说明多重搜索下的错误率，而不是单次样本内的高信息系数。可追溯性（数据来源、时间口径、公式、逐期样本外表现、已知限制）是有效性的**必要条件，不是替代品**：证据齐全但关系不稳定，仍不算有效因子。

### 现状与差距（如实标注，不得抹平）

现有 `research_engine.temporal` 的判定状态只有 `provisional`（暂时通过）与 `insufficient_evidence`（证据不足），研究库状态为 `exploratory`；筛选允许「不选」，不提供多重搜索错误率保证。2026-11-13 的冻结留出验收通过数为零、完整方法增益标准未通过，面板交互项与神经闭环的预设效果标准同样未通过。

即：旧入口被设计成「可以诚实地不给结论」，而本阶段目标要求「给出经得起检验的肯定结论」。**这不是工程缺陷，是验收标准的改变**。2026-11-14 新增的独立判定层 `research_engine/effectiveness.py` 已提供 `effective` 终态，它**消费冻结输出、不修改旧入口语义**，两者并存、职责不同。`docs/factor_research.md` 描述的是旧实现，与目标并存，不得改写其中的限制声明来冒充已达成。

**2026-11-15 收尾状态（历史对照）**：手写模板路线在真实 A 股数据的多轮独立历史样本外预注册上认证出 **6 个横截面有效因子**（见 `effective_factor_registry.json`），并如实登记 1 个族级不显著轮次与 1 个通道二全证伪轮次。该口径证明的是**认证流程**可重复执行并如实给出肯定 / 否定结论，**不证明搜索侧有发现能力**；这批因子自 11-15 起降级为历史对照。当前主线是下文「搜索侧主线改版」的本地仿 Qlib 学得因子流程。**「稳定产出」始终指流程可重复，不宣称跨轮稳定、跨轮序贯错误率或未来持续。**

**搜索侧主线改版（2026-11-15，Anthony 明确否决旧路线）**：手写模板 + 枚举筛选路线已作废——「随机生成一堆公式去跑验证完全不高效」「模板也是屎」「因子不是一拍脑袋想出来的，是从数据里面学来的」。新指令是**原模原样按 Qlib 搭**、可用 Alpha158 / Alpha101 这类标准先验但**不得拿模板乱套**，且「别直接调接口，参考模仿自己本地写」以便后期改造。据此落地 `src/dynaloop/learned_factors/`：本地仿写 `provider`（Qlib 二进制归档）→ `expression`（Qlib 算子语义，含回归三算子的最小二乘等价实现）→ `alpha158`（158 个标准特征与默认标签，配置结构原样复刻）→ `handler`（`DataHandlerLP` 默认处理器）→ `dataset`（`DatasetH` 三段）→ `model`（`LGBModel` 默认超参，封装 `lightgbm`）→ `workflow`（`workflow_by_code.py` 四环节 + `SigAnaRecord` 风格描述性指标）。**不 import `pyqlib`**，逐层可替换。模型训练是真正的学习，学得因子 = 冻结模型在验证期的预测分数；第五层认证出口不变，见 `docs/learned_factor_workflow.md`。

**旧路线的地位（如实，不得抹平）**：15 个手写模板、`factor_search.py` 枚举筛选、DEAP 文法随机采样与乘性权重抽样、以及 `effective_factor_registry.json` 里的 6 个已认证因子，全部**降级为历史对照**，不得当作研究能力或交付成果。六段闭环里的神经大脑仍是**暂缓、非放弃**。统计保证只保护结论（冻结在先、验证期不回流、族级错误率控制），不依赖搜索侧的智能程度，也不能反过来证明搜索侧有能力。真实数据一次性冻结验证已出结论（`preregistered_learned_20261115/`）：58 期样本外、族级 p=0.0060、月度排序信息系数 +0.0362、稳定性与留一法全通过，学得因子判定为**「横截面有效因子」**；不宣称盈利、未来持续与跨轮序贯。仍存差距：商业级时点成分股、行业 / 市值中性化、去极值、冗余度与容量扫描、A 股逐笔撮合约束、第六层前向跟踪。

### 判定口径已定稿（2026-11-14，统计学立场，非照抄）

完整口径与一手依据见 **[有效因子的统计判定口径](effective_factor.md)**，实现为 `research_engine/effectiveness.py`。**不是把 Qlib / RD-Agent(Q) 搬过来**：它们的验证单元只做去冗余 + 回测 + 信息系数更新最优集合，不校正产生候选的搜索规模、不预注册冻结、不给出「有效」断言的错误率陈述。我们的立场是统计学的——有效因子是**带错误率陈述的肯定断言**，不是高信息系数。

三根支柱，全部落在**冻结后的独立窗口**：

- **支柱 0 因果隔离（最关键、本项目自己的想法）**：自进化研究器反复查询同一批数据，会让留出集本身被过拟合（Dwork 等，Science / NeurIPS 2015），固定族多重检验假设随之失效。我们**不在自适应回路内部硬控序贯错误**，而是利用金融时序的因果箭头：全部自由度限于搜索期，在声明的截止日一次性冻结候选族与每个参数并落指纹，冻结文件落盘之后才允许构造验证期数据；验证期是冻结日之后的**历史样本外**数据，一次性评分。隔离是流程 / 信息隔离，不是等未来数据物理到达（Anthony 2026-11-15 定调）；验证期信息不可能倒流进冻结族，于是自适应难题被**设计消除**，结论变回标准的预注册族假设检验。窗口被查看即消耗，再搜索须开新族、用新区间并登记前序轮次。这是「结论的因果位置」的重新安排，不是换更强模型或更多因子。
- **支柱 1 抗数据窥探的族级检验**：检验对象是冻结族里最好的那个；逐期损失差分要求**每期同时胜过零预测与历史均值两条基线**；平稳区块自助法每个复制对全族**共用同一条时间索引路径**（同时保住序列相关与候选间相关），按样本均值重新中心化构造无优越性零假设；最大统计量逐步下降给出调整后 p 值与族级错误率陈述。明确标注这是**保守的现实检验风格变体，不是完整 SPA**（学生化尺度固定、不剔除劣质候选）。
- **支柱 2 稳定性与可重复性（独立必要条件）**：不相交时间块至少 75% 方向一致、去掉贡献最大一期后改善仍为正、预测与收益平均同向。块级符号检验 p 值只作诊断，不宣称独立显著。

**精确口径**：冻结族内**宣称族级错误率 ≤ α**（条件：隔离成立、区块自助法保持依赖、零假设近似枢轴、验证期平稳）；**跨轮自适应 / 序贯错误率不宣称**（由隔离消除，不是被检验约束）；共形覆盖、盈利、因果、未来持续**一概不宣称**；验证期少于 24 期自动附功效警示。终态为 `effective` / `insufficient_evidence` / `refuted`，全部证据与假设写进 `spec` 并由指纹保证可复现。

**实证（2026-11-14，真实数据）**：3 个冻结候选、9 期独立留出，族级 p = 0.9840、有效因子 0、2 个被证伪；适配器逐期结果与 11-13 独立留出实验零差异。这与「通过数为零」一致，说明**防假发现生效**。

**通道一落地（2026-11-15）**：第二条通道已按自己的口径实装，权威文件 **[横截面有效因子的统计判定口径](cross_section_factor.md)**，实现 `research_engine/cross_section.py`。零假设是**无相对排序能力**、基线是**随机排序 / 等权**（通道二的零预测 / 历史均值在横截面上是常数向量、排序恒为并列，根本不是有效基线），逐期排序信息系数按 \(\sqrt{N_t-1}\) 加权——**宽度只降低每期测量噪声，不制造独立期数**。三支柱与通道二同源（因果隔离、全族共用时间索引路径的区块自助 + 最大统计量逐步下降、跨期稳定性与留一法），但族、统计量、零假设、基线、随机流盐全部独立；评估指标与晋升门槛严格对齐 Qlib / alphalens 等上游实践（权威表见 `docs/factor_evaluation_baseline.md`）：排序信息系数及其比率、t 统计量、分组收益、多空毛净、换手、信息比率均**显式报告**；分组单调性、多空双腿方向、净价差为描述性诊断，不作一票否决。`channels.py` 提供通道标签、带指纹证据条目与混族硬拒绝，`resampling_tools.py` 只共用数学算法。`effectiveness.py` 重构后补上「择时有效因子」标签，11-14 实证族级 p = 0.9840 与指纹**逐位复现**。

**真实数据处置（如实）**：`experiments/factor_stream/cross_section_assessment.py` 在 qlib 归档上构造了 259 个月末时点横截面（2005-04-29 至 2026-10-30，决策与成交分离、标签成熟后评分、缺失标签保留为空）。旧版把「冻结日之前可得、可能被回看」误当成不能认证，标记 `WITHHELD` 只出诊断，这是口径错误（Anthony 2026-11-15 纠正：用过去数据做因子、不泄露地在之后历史窗口有效，就是有效）。现已改为**历史样本外预注册**：搜索 / 冻结 / 验证三段全在历史数据内，冻结文件先落盘，验证期一次性评分。多轮独立预注册与消耗窗口逐轮登记，跨轮序贯错误率不宣称。

**仍存在的差距（不得抹平）**：真实数据认证已在多轮独立预注册上执行：前几轮给出否定结论（族级显著但被旧版自创门槛拦下，或族级未过），改用 Qlib / alphalens 权威口径后**已认证出经得起族级检验的有效因子**；下一步是扩大窗口与标的池、补齐商业级时点成分股数据底座、中性化与去极值、冗余度与容量扫描；因子排序自相关与纽维–韦斯特修正 t 值已按上游口径补齐并仅作报告。**不得放宽族级错误率、稳定性、留一法或期数下限来凑结论**，也不得把单轮肯定结论外推为跨轮或未来持续；`docs/factor_research.md` 描述现有研究器实现及其限制，不得改写其限制声明冒充已达成。

### 现有工作流与对照要求

原 LoopOrchestrator 是固定历史窗口上的多轮探索，默认按模板概率采样，不是完整遗传进化。新增 research_engine.temporal 沿时间推进，复用模板、表达式、探索策略和权重更新组件。Wake 使用近期成熟标签；Sleep 使用已发生历史窗口回放。这里是受 Wake–Sleep 启发的工作流，不是经典 Helmholtz machine 算法或扩散生成市场。

主要证据是未来区间中的因子关系、稳定性和重复性；交易成本回测是辅助诊断。必须比较随机滚动搜索、仅 Wake、等预算近期回放及全量滚动参考。漂移告警只反映观测分布变化，不自动证明条件关系变化。不得用未来才形成的因子证据回填过去。运行说明见 factor_research.md，实验协议见 experiments/factor_stream/PROTOCOL.md。

### 中低频定位、个人研究版与双通道（Anthony 2026-11-15 定调，当日二次修订）

完整规范见 **[中低频研究流程规范（Part A · 个人研究版）](research_process.md)**，它是流程与验收口径的权威来源；架构 / 算法 / 评估类任务开工前必读。

- **定位**：本项目是**面向个人的研究系统**，不是资管产品。机构流水线只作参照系，用来区分「结论正确性」与「资金规模 / 合规的副产品」。可裁剪容量扫描、借券融资与冲击成本精细建模、制度化上线治理、商业级时点成分股重建（须标注幸存者偏差未消除）、正式立项系统；**不可裁剪**时点数据、防前视、决策与成交分离、预注册冻结、族级错误率控制、稳定性与留一法、全参数留痕、成本与换手显式且毛净并列；分组单调性等仅为描述性报告（见基线文档）。个人研究没有内控与同行评审，统计层反而更该硬——**能省的是成本，不是证据**。
- **频率**：日线数据，决策周期日 / 周 / 月量级，默认持有期 21 个交易日、月度调仓；决策与成交分离、标签成熟后评分；频率 / 持有期 / 调仓间隔进规格与指纹；分钟 / 小时数据不得混入同一判定族凑样本量。年约 12 个独立决策期，功效靠通道一的横截面宽度或通道二的时间长度补，禁止提频、缩间隔或放松门槛。
- **双通道（核心，均已实装）**：**通道一 选股（横截面）** 问「同一时点谁比谁更强」，零假设 = 无相对排序能力，基线 = 随机排序 / 等权，功效靠宽度，实现 `cross_section.py`、权威口径 `docs/cross_section_factor.md`；**通道二 择时（单标的时序）** 问「这只接下来方向 / 关系如何」，零假设 = 不胜过零预测与历史均值，功效靠时间长度，实现 `temporal.py` / `effectiveness.py` / `catalog.py`、权威口径 `docs/effective_factor.md`。两者都是合法研究对象，现有代码不是缺陷、不是白写。
- **不得合并**：零假设、基线、样本结构全不同，混进同一判定族会让族级错误率控制失效。各自预注册、各自冻结、各自晋升、各自出带指纹的证据条目；输出结论必须带「横截面有效因子 / 择时有效因子」通道标签——**已写入两份判定器的报告、逐候选结论与 `spec`**，`enforce_channel` 对混族直接抛错。两类证据互相不得外推。
- **流水线**：L0 假设登记 → L1 时点数据底座 → L2 标准化与中性化 → L3 单因子诊断 → L4 组合层现实化 → L5 冻结样本外晋升门禁 → L6 上线后监控，各层个人版裁剪标注见规范第四节。L5 是各通道「有效」断言的唯一出口，两通道各自执行。**合成两类证据属于 Part B**，Part A 不负责。
- **现状**：L1–L4 横截面环节（时点标的池、防前视、决策成交分离、标签成熟、分组单调性、多空分腿、换手与成本毛净并列）、两通道标签与独立族登记、L5 的因果隔离 / 族级错误率控制 / 跨期稳定性 / 全参数留痕均已实装；真实横截面数据底座复用既有 qlib 归档，259 个月末横截面已可跑通诊断并生成预注册冻结文件。**尚未补齐**：商业级时点成分股重建（现标 `approximate`、幸存者偏差未消除）、行业 / 市值中性化与去极值、冗余度与容量扫描、L6 前向跟踪台账；真实数据的有效因子认证结果以 `experiments/factor_stream/preregistered_*` 各轮产物为准，逐轮登记冻结族、消耗窗口与结论。11-14 实证只对一只创业板指数基金 / 9 期 / 通道二有效。
- **工程默认值已定稿（2026-11-15，Anthony 授权 AI 全权决定）**：标的池形态、默认调仓节奏、通道二是否允许多标的合并、A 股撮合参数、L4 在 A / B 的边界、A→B 接口形态六项均已在 `docs/research_process.md` §8 定稿并写明理由与可回退性；它们是**工程默认值，不是统计门槛**，只对新轮预注册生效，不得回头改已冻结轮次。任何情况下不得为凑出有效因子而放松判定口径。

## 以下为历史神经实验说明，不代表当前产品路线

## 产品目标

DynaLoop 是创新且可靠的 QUANT × AI 开源工程：复用因子、数据与模拟执行能力，让可训练模型持续利用真实市场反馈学习，并让每次更新能够重放、比较和追踪。不以发表论文为目标，不承诺盈利，也不把持续更新本身等同于改善。

## 大脑与执行

大脑主路线是小型 Looped Transformer：同一组 Transformer 核心参数沿计算深度循环，输入行情与因子历史窗口，输出未来收益分数。循环计算不等于在线学习。现有因子搜索和执行模块继续复用，后续保留 GRU、普通小型 Transformer 等对照。

当前已加入神经大脑、真实标签驱动的 Wake、完整检查点和下一根 bar 执行的回测通路；具体输入、限制与运行方式见 [大脑工程说明](brain.md)。阶段 0–5 历史实现见 system_contract.md，不把旧代理模型当成扩散生成器。

## Wake 与 Sleep

Wake 只用真实数据：先预测，等待持有期结束后得到标签，再更新模型。窗口、特征模式、标签成熟时刻与模型版本必须明确，尾部尚未成熟标签不得伪造。

Sleep 已加入神经路径：独立条件扩散模型从历史可用信息生成不同于实际历史、但满足约束的替代路径。当前使用价格收益率与价格衍生因子，因子与目标标签从同一路径重新计算；真实回放与合成样本共同训练候选大脑。指标到行情通常不是唯一反演，没有因果假设不能宣称因果反事实。

Sleep 候选在后续真实数据上与当前版本影子比较；先预测后评分，达到固定数量的成熟标签后以真实 MSE 决定晋升或丢弃。另设独立 Wake-only 与相同额外训练预算的真实回放对照。真实评估标签只在成熟后用于后续在线学习，不得倒用于已评分预测或以测试结果调参。生成器、候选、回放、待成熟标签与随机状态均可保存，当前闸门属于工程决策，不提供统计不退化保证。

## 验证原则

工程验收包括因果时间顺序、恢复一致性、输入约束、可追踪配置、执行成本和失败行为。模型效果用真实数据前向评估，分开检验循环结构与在线/Sleep 更新的价值；合成夹具只证明代码路径可运行。

统计工具服务于诊断和决策。现有 stepdown、重采样和代理校准不自动提供跨轮错误率、生成偏差控制或不退化保证。未拒绝退化不等于证明不退化。相关保证必须另行说明对象、假设与证据。
