# Data and UI contract

更新：2026-11-11。修改数据源、回测接入或图表时按需读取；这里记录当前行为，不记录开发历史。

## Sources and capabilities

- 数据源是可注册的取数配方。请求参数、原始列、解码布局、频率和复权能力由 Data 声明并通过公开接口提供，上层不猜测厂商字段。
- 注册 / 编辑时自动探测并缓存能力，无需改代码或重启；成功探测的 OHLC 数据可立即回测，失败返回真实错误并支持 reprobe。内置 preset 只作兜底，不能成为新源准入条件。
- 缓存带 `schema_version`；规则升级后自动重探旧版本。新响应布局超出探测能力时如实失败，不承诺任意未知格式均可自动识别。
- 只按响应证据推断列名，推断结果标记 `inferred`。优先检验 OHLCV 数值关系；证据不足保留 `column_N`。禁止按供应商字段位置猜名称，禁止用 `close × volume` 冒充成交额。
- 频率由源声明 `frequency_options`，控件支持自由输入；规范 id 包括 `1m/5m/15m/30m/60m/1d/1w/1M`。按源保存的参数形状编码请求，不按 source_key 分支；无法可靠控制的参数保持原值并禁用控件。
- 时间戳保留时分秒。引擎只比较有序事件，不推测频率、交易日历或时区；调用方应提供一致可排序的时间表示。日内源只返回近期数据时记录实际 `resolved_window` / `recent_window`，不能假装获得请求的历史区间。
- 对声明可控的复权参数，空字符串表示明确选择不复权，必须覆盖预设的 qfq/hfq；不能按“未提供参数”处理。实验需核对实际 request_spec，不能只信请求选项元数据。

## Results and replay

- 分开保存 Data 原始 records（tape）、引擎结果、pane 声明和 `setup.view_config`。视图元数据不能进入引擎 `Bar` 或 resolved config。
- 源提供的数值列都应可绘制，包括 `column_N`；没有的列不创建面板、不显示缺列说明、不编造数值。默认显示全部可用面板，勾选用于隐藏。
- SMA / MACD / RSI 等派生指标与原始列分开，复用 `ta` 等成熟库；缺少输入列时不创建该指标面板。
- 图例由 `pane.series` 生成；各面板共享 x 轴与 playhead。切换可见性只改 view_config，不重跑引擎。
- 主价格图使用真实 OHLC 蜡烛，保留叠加指标和买卖标记。

## Language

用户可见文案全英文，金融术语、单位及图例准确；证券使用英文显示名、代码原样保留。采用涨红跌绿，货币符号 ¥ 可保留。前端改动后检查 `frontend/src` 的 CJK 字符。
